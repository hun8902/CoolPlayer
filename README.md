# Cool Player

Cool Player는 FLAC 음원을 ALAC 기반의 고음질 음악 파일로 정리하기 위한 macOS 데스크톱 앱입니다.

여러 FLAC 파일을 한 번에 추가한 뒤 원본 음원 정보를 확인하고, 앨범 커버와 메타데이터를 정리하며, LRC 실시간 가사를 관리하고, 선택한 출력 품질로 ALAC 파일을 생성하는 작업 흐름을 제공합니다.

## 프로젝트 개요

Cool Player는 이후 iPhone용 ALAC 플레이어 앱과 연결될 수 있는 음악 라이브러리 정리 도구를 목표로 합니다.

단순히 파일을 변환하는 것만이 아니라, 변환 전에 원본 음원의 상태를 확인하고, 곡 정보와 앨범 커버를 정리하고, 실시간 가사 파일까지 함께 준비하는 데 초점을 둡니다.

주요 사용 흐름은 다음과 같습니다.

1. FLAC 파일 또는 폴더를 앱에 추가합니다.
2. 앱이 각 파일의 원본 음원 정보를 분석합니다.
3. 파일 리스트에서 변환할 파일을 선택합니다.
4. 선택한 파일의 상세 정보, 앨범 커버, 메타데이터를 확인합니다.
5. 필요한 경우 제목, 아티스트, 앨범 정보와 앨범 커버를 수정합니다.
6. LRC 실시간 가사를 검색하거나 직접 편집합니다.
7. 출력 품질과 저장 위치를 정합니다.
8. 선택한 파일을 ALAC 파일로 변환합니다.
9. 변환된 파일을 앱 안에서 재생해 정상 출력 여부를 확인합니다.

## 주요 기능

### FLAC 파일 관리

- FLAC 파일 추가
- 폴더 단위 추가
- 여러 파일 동시 관리
- 전체 선택
- 전체 선택 해제
- 선택 파일 제거
- 파일별 앨범 커버 썸네일 표시
- 파일별 원본 음원 정보 표시

파일 리스트는 앱의 기준 작업 공간입니다.

사용자는 왼쪽 파일 리스트에서 변환할 파일을 체크하고, 오른쪽 작업 영역에서 변환, 상세 정보, 가사, 기록을 확인합니다.

### 원본 음원 정보 분석

앱은 추가된 FLAC 파일의 기본 음원 정보를 분석해 파일 리스트와 상세 정보 화면에 표시합니다.

표시 대상 정보는 다음과 같습니다.

- 오디오 포맷
- bit depth
- sample rate
- 채널 정보
- 재생 길이
- 제목
- 아티스트
- 앨범
- 앨범 커버 유무

예시:

```text
FLAC / 24-bit / 96kHz
FLAC / 16-bit / 44.1kHz
```

### ALAC 변환

선택한 FLAC 파일을 ALAC 형식의 `.m4a` 파일로 변환합니다.

변환 탭에서는 다음 정보를 확인할 수 있습니다.

- 전체 파일 수
- 변환 대상으로 선택된 파일 수
- 선택된 출력 품질
- 저장 위치
- 변환 대상 목록
- 현재 변환 상태
- 변환 진행률

변환 대상은 왼쪽 파일 리스트에서 체크된 파일만 포함됩니다.

### 출력 품질 선택

사용자는 변환 결과물의 출력 품질을 선택할 수 있습니다.

지원하는 출력 형식은 다음과 같습니다.

- ALAC 16-bit / 44.1kHz
- ALAC 24-bit / 48kHz
- ALAC 24-bit / 96kHz
- ALAC 24-bit / 192kHz
- 원본 해상도 유지

출력 형식은 음질, 용량, 사용 목적에 따라 선택할 수 있도록 구성되어 있습니다.

### 메타데이터 수정

상세 정보 화면에서는 선택한 파일의 곡 정보를 확인하고 수정할 수 있습니다.

수정 가능한 정보는 다음과 같습니다.

- 제목
- 아티스트
- 앨범
- 앨범 커버

앨범 커버가 없는 파일은 앱에서 커버 확인을 시도하고, 사용자가 직접 커버 이미지를 선택해 교체할 수도 있습니다.

### LRC 실시간 가사

가사 화면에서는 선택한 파일 기준으로 LRC 실시간 가사를 관리합니다.

지원하는 작업은 다음과 같습니다.

- 가사 검색
- LRC 형식 가사 표시
- 가사 직접 편집
- `.lrc` 파일 저장
- 선택한 곡이 바뀔 때 해당 곡 기준으로 가사 내용 갱신

LRC 파일은 아래와 같은 형식을 사용합니다.

```text
[00:12.30]첫 번째 가사
[00:18.10]두 번째 가사
[00:24.50]세 번째 가사
```

저장할 때는 원본 음원 파일명과 같은 이름을 기본값으로 사용합니다.

### 변환 히스토리

히스토리 화면에서는 앱에서 수행한 주요 작업 이력을 확인할 수 있습니다.

기록 대상은 다음과 같습니다.

- 변환 완료
- 메타데이터 저장
- 기타 주요 작업 결과

### 재생 확인

앱 하단에는 변환 완료 파일을 확인하기 위한 플레이어 바가 있습니다.

변환이 끝난 뒤 결과 파일을 바로 재생해 출력 파일이 정상적으로 만들어졌는지 확인할 수 있습니다.

## 화면 구성

### 왼쪽 파일 리스트

앱에 추가된 FLAC 파일을 관리하는 영역입니다.

파일명, 앨범 커버, 원본 음원 정보, 선택 상태를 한눈에 확인할 수 있습니다.

### 변환 탭

선택한 파일을 ALAC로 변환하는 작업 화면입니다.

출력 품질, 저장 위치, 변환 대상, 진행률을 확인합니다.

### 상세 정보 탭

선택한 음원의 상세 정보와 앨범 커버를 확인하고 수정하는 화면입니다.

### 가사 탭

선택한 곡의 LRC 실시간 가사를 검색, 편집, 저장하는 화면입니다.

### 기록 탭

변환 및 수정 작업의 결과를 확인하는 화면입니다.

### 앱 정보 탭

앱의 기본 정보를 확인하는 화면입니다.

## 사용 목적

Cool Player는 다음과 같은 작업을 한 앱 안에서 처리하는 것을 목표로 합니다.

- 고음질 FLAC 음원 정리
- iPhone용 ALAC 파일 준비
- 음원 메타데이터 정리
- 앨범 커버 정리
- LRC 실시간 가사 파일 준비
- 변환 완료 파일 재생 확인
