# Cool Player for Android

기기에 저장한 음악과 가사를 함께 듣는 안드로이드 플레이어입니다. Android 8.1(API 27) 이상에서 설치할 수 있습니다.

## 1.4.0 · GitHub 업데이트

[Android APK 다운로드](https://github.com/hun8902/CoolPlayer/releases/download/android-v1.4.0/Cool-Player-Android.apk)

설정 → **앱 업데이트 → 업데이트 확인**에서 새 Android 릴리스를 찾고 다운로드합니다. 다운로드가 끝나면 **설치**를 누르고 Android 설치 화면에서 업데이트를 확정하세요. Android가 설치 권한을 요청하면 Cool Player의 ‘이 출처 허용’을 켜고 돌아옵니다.

**새 버전 자동 확인**은 앱을 열 때 하루 한 번 확인하며 설정에서 끌 수 있습니다. APK는 동의 없이 다운로드하지 않습니다. 파일의 SHA-256, 패키지명, 버전, 기존 서명키를 확인하고 설치 화면을 엽니다. 확인 요청은 GitHub에 연결하며 음악 파일은 보내지 않습니다.

1.3.0 이하에는 업데이트 기능이 없으므로 1.4.0 APK를 한 번 직접 설치해야 합니다. 기존 앱을 삭제하지 않고 설치하면 보관함과 설정이 유지됩니다. 다운로드 중 앱 프로세스가 종료되면 설정에서 다시 다운로드하세요. 완료한 다운로드는 설정의 **다운로드한 업데이트 설치**로 다시 열 수 있습니다.

## 1.3.0 · 메뉴 통일과 앨범아트 변경

- 곡/가사 메뉴, 검색과 편집, 정렬, 선택 목록, 확인창을 공통 패널로 통일했습니다. 좁은 화면에서는 하단 패널, 넓은 화면에서는 폭을 제한한 중앙 패널을 사용합니다.
- 재생 대기열에 앨범아트와 현재 곡 표시, 곡별 위/아래 이동 및 제거를 추가했습니다.
- 설정은 그룹형 목록으로 바꾸고 화면 모드, 가사 스크롤, 속도, 취침 타이머의 선택값을 표시합니다.
- 가사 검색 결과에도 앱의 서체, 간격, 배경 스타일을 적용했습니다.
- 앨범아트: 재생 화면의 **앨범아트 변경**, 곡 메뉴의 **앨범아트 가져오기 · 변경**, 설정의 **현재 곡 앨범아트**에서 접근합니다.
- 이미지 파일 선택, HTTPS 이미지 주소로 가져오기, 원본 음원의 내장 앨범아트 다시 읽기를 지원합니다. 검색어로 인터넷 앨범아트를 찾는 기능은 포함하지 않았습니다.
- 변경한 이미지는 앱 보관함에 저장하고 대기열 메타데이터에도 반영합니다. 원본 음원 파일에 태그를 쓰지는 않습니다.

## 1.2.0 · 곡 선택과 화면 전환

- 곡 행 자체에 재생 클릭과 길게 누르기를 연결했습니다. 행 내부의 메뉴 버튼 때문에 ListView의 곡 선택 이벤트가 막히던 구조를 수정했습니다.
- 미니플레이어에서 전체 플레이어로 열 때 위로 펼쳐지고, 닫을 때 아래로 내려가는 전환을 추가했습니다. 탐색 탭과 앨범/가사 전환에도 짧은 이동·투명도 애니메이션을 적용합니다.
- 실제 앨범아트 색상을 추출한 부드러운 그라데이션 배경을 추가했습니다. 라이트/다크 모드에 맞춰 밝기를 조절하고 색상 변경은 서서히 반영합니다.
- 시스템에서 애니메이션을 끄면 화면 전환과 배경 색상 전환도 즉시 적용합니다.

## 1.1.0 · 폴더블 화면과 새 UI

- 펼친 폴드·태블릿의 재생 화면: 왼쪽 앨범아트/재생 제어, 오른쪽 실시간 가사.
- 좁은 화면: 앨범/가사 탭 전환. 재생 위치와 이전/재생/다음 컨트롤은 화면 아래에 유지.
- 창 너비에 맞춘 레이아웃 전환과 Jetpack WindowManager를 통한 접힘 경계 정보 반영.
- 넓은 화면의 세로 탐색 메뉴, 커버 중심 앨범 그리드, 앨범아트가 있는 미니플레이어.
- 문자 기호 대신 벡터 재생 아이콘, 현재 곡 표시, 간결한 곡 정보, 가사 타이밍 별도 메뉴.
- 가사를 손으로 스크롤하는 동안 자동 따라가기를 잠시 멈춥니다.

동일한 앱 ID와 서명 키를 사용하므로 1.0.0 위에 업데이트 설치할 수 있습니다. 앱을 삭제하지 않으면 보관함과 저장한 가사를 유지합니다. 실제 폴드 기기에서의 접힘 전환과 UI 기능 테스트는 수행하지 않았습니다.

## 포함한 기능

- **로컬 음원 재생**: FLAC, WAV, MP3, AAC/M4A, Ogg, Opus. 파일 선택 또는 폴더·하위 폴더 가져오기. 원본 파일을 변환하거나 서버에 업로드하지 않습니다.
- **보관함**: 앨범아트·제목·아티스트·앨범·재생시간 읽기, 제목/가수/앨범 검색, 정렬, 앨범별 보기, 즐겨찾기, 재생목록.
- **재생**: 대기열, 다음에 재생, 셔플, 한 곡/전체 반복, 위치 이동, 속도 조절. 마지막 대기열과 재생 위치를 저장합니다. 앱을 열었을 때 자동으로 소리를 재생하지 않습니다.
- **백그라운드**: Media3 재생 서비스, 미디어 알림과 잠금화면 제어, 오디오 포커스 처리, 이어폰 연결이 끊어지면 일시정지.
- **가사**: 한 번 눌러 검색하고 앱에 저장, 곡명/가수 수동 검색, Bugs와 LRCLIB, Bugs 결과 추가 페이지 로딩, 적용 전 미리보기. LRC/TXT 가져오기·편집·내보내기. 폴더를 추가할 때 같은 파일명의 LRC/TXT도 읽습니다.
- **실시간 가사**: 재생 시간에 맞춘 현재 줄 강조와 자동 스크롤, 줄을 눌러 해당 위치로 이동, 곡별 0.5초 타이밍 보정. 시간 정보가 없는 가사는 일반 텍스트로 표시합니다.
- **홈 화면 위젯**: 앨범아트, 곡명/가수, 이전/재생·일시정지/다음. 앱 설정에서도 위젯 추가를 요청할 수 있습니다.
- **설정**: 라이트/다크/기기 설정, 가사 자동 스크롤, 취침 타이머, 기기의 시스템 이퀄라이저 열기(지원 기기).

## 사용하기

1. APK를 안드로이드 기기로 옮겨 설치합니다.
2. 오른쪽 위 **＋**에서 음원 파일 또는 음악 폴더를 선택합니다. 전체 저장소 접근 권한 대신 선택한 파일과 폴더의 접근 권한만 사용합니다.
3. 곡을 누르면 재생됩니다. 화면 아래 곡명을 누르면 앨범아트와 가사가 있는 재생 화면이 열립니다.
4. **가져오기**를 누르면 현재 곡명과 가수로 가사를 찾아 저장합니다. 결과가 없으면 가사 메뉴의 **곡명·가수 직접 검색**에서 검색어를 수정합니다.
5. 가사 줄을 누르면 해당 재생 위치로 이동합니다. 타이밍이 맞지 않으면 하단의 ±0.5초로 조정합니다.
6. 홈 화면을 길게 누른 뒤 위젯에서 **Cool Player**를 선택하거나 앱 설정의 위젯 추가를 사용합니다.

가사를 가져오면 앱 내부 저장소에 LRC/TXT 파일과 보관함 정보가 저장됩니다. 원본 음악 폴더에 임의로 파일을 쓰지 않습니다. 별도 파일이 필요하면 **가사 파일 내보내기**에서 저장 위치를 선택하세요. 앱 삭제 시 내부 데이터도 삭제되므로 필요한 가사는 먼저 내보내세요.

## 지원 범위

FLAC 파일 재생과 출력 장치의 비트퍼펙트 출력은 별개입니다. 실제 출력 샘플레이트는 안드로이드 믹서와 연결된 오디오 장치에 따라 달라지며, 전용 USB DAC 직접 출력은 포함하지 않습니다. ALAC는 플랫폼 디코더가 지원하는 기기에서만 재생될 수 있으며 범용 ALAC 소프트웨어 디코더를 포함하지 않았습니다.

가사 검색 결과는 제공처의 등록 여부와 연결 상태에 따라 달라집니다. 가사 검색을 요청했을 때만 곡명과 가수 이름이 Bugs와 LRCLIB로 전송됩니다. 음원 파일은 전송하지 않습니다. 자동 검색은 제목과 가수가 일치하는 결과만 적용하며 동기화 가사를 우선합니다.

macOS 앱의 음원 변환과 원본 태그 쓰기, Android Auto 브라우징, 전용 USB 오디오 출력은 이 안드로이드 버전에 포함하지 않았습니다. 앱 내부에서 원본 음원을 삭제하지 않습니다.

## 빌드

필요 도구: JDK 17 이상(작성 시 JDK 21 사용), Android SDK Platform 36, Build Tools 36.0.0. Gradle 8.13 wrapper가 포함되어 있습니다.

```sh
# local.properties에 sdk.dir=/안드로이드/SDK/경로 설정
./gradlew assembleDebug
```

출력: `app/build/outputs/apk/debug/app-debug.apk`.

릴리스 APK는 별도 서명 키를 사용합니다. 서명 설정은 소스에 포함하지 않습니다. 다음 형태의 속성 파일을 저장소 밖에 만들고 경로를 환경변수로 넘깁니다.

```properties
storeFile=/private/path/cool-player-release.jks
storePassword=YOUR_PASSWORD
keyAlias=cool-player
keyPassword=YOUR_PASSWORD
```

```sh
COOLPLAYER_SIGNING_PROPERTIES=/private/path/release.properties ./gradlew assembleRelease
```

출력: `app/build/outputs/apk/release/app-release.apk`. 같은 앱을 업데이트하려면 기존 서명 키를 유지해야 합니다. 서명 설정 없이 빌드한 릴리스는 서명되지 않습니다.

## 구성

- `MainActivity.java`: 보관함, 재생 화면, 가사 검색/편집, 설정.
- `PlaybackService.java`: Media3 재생 세션, 오디오 포커스, 대기열 저장, 취침 타이머.
- `Library.java`: SAF 파일/폴더 읽기, 메타데이터, 보관함 저장.
- `Lyrics.java`: Bugs/LRCLIB 검색과 가사 파싱.
- `PlayerWidget.java`: 홈 화면 위젯과 재생 세션 연결.

Media3 ExoPlayer/Session, AndroidX Annotation 및 Gradle을 사용합니다. 해당 구성요소의 라이선스는 각 공식 프로젝트에 따릅니다.

이 전달본은 APK 컴파일과 패키징을 완료한 상태입니다. 요청에 따라 실제 기기 재생·UI·위젯 기능 테스트는 실행하지 않았습니다.
