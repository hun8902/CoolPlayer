Cool Player for Android 1.4.6 (versionCode 31)

- 높이가 낮은 가로 화면에서는 앨범아트를 배경으로 표시하고 작은 커버를 숨겨 곡 정보와 재생 버튼을 보기 편하게 개선했습니다. 화면을 회전하거나 펼치면 기존 배치로 자동 복귀합니다.
- 작은 화면에서 미니 플레이어가 왼쪽 메뉴를 가리던 문제를 수정했습니다. 메뉴가 화면보다 길면 스크롤하여 설정까지 이동할 수 있습니다.
- 음악 검색과 이름 입력에서 키보드의 완료 버튼을 누르면 키보드가 닫힙니다.
- 입력란 밖을 터치해 키보드를 닫을 수 있습니다. 다른 입력란으로 이동하거나 목록·버튼을 누르는 동작은 그대로 사용할 수 있습니다.

Cool Player for Android 1.4.5 (versionCode 30)

- 플레이어의 … 메뉴에 ‘전체 화면 가사’를 추가했습니다.
- 전체 화면에서 앨범아트 배경에 어두운 레이어와 그라데이션을 적용하고 큰 가사를 표시합니다.
- 전체 화면 하단에 재생 위치 조절, 이전 곡, 재생·일시정지, 다음 곡 버튼을 제공합니다.
- 전체 화면에서 뒤로가기 또는 상단 화살표를 누르면 기존 플레이어로 돌아갑니다.
- 곡 전환 시 전체 화면의 가사와 배경을 갱신하도록 처리했습니다.
- 전체 화면 진입 시 발생하던 레이아웃 삭제 충돌을 수정했습니다.
- 새 메뉴의 지원 언어 번역을 추가했습니다.

Cool Player for Android 1.4.19

- 홈 위젯에서 재생 서비스를 시작하는 방식을 수정했습니다.
- 가로 플레이어의 제목과 재생 버튼 사이 과도한 빈 공간을 줄였습니다.
- 재생목록 위젯 기본 높이와 작은 위젯의 안쪽 여백을 조정했습니다.
- 최근 앱에서 밀어서 닫을 때 재생을 중지하는 수정이 포함되어 있습니다.
