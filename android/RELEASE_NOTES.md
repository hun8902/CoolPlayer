앱 설정에서 GitHub의 새 Android 버전을 확인하고 다운로드할 수 있습니다.

- 설정 → 앱 업데이트 → 업데이트 확인
- 앱 실행 시 하루 한 번 새 버전 자동 확인, 설정에서 켜기/끄기
- 다운로드 진행률과 설치 안내
- APK 체크섬, 패키지명, 버전, 기존 서명키 확인 후 Android 설치 화면 연결
- 기존 음악 보관함과 설정을 유지하는 업데이트 설치

폴드의 좌우 재생·가사 화면, 앨범아트 배경, 통일된 메뉴, 재생 대기열, 가사 검색, 홈 화면 위젯을 포함합니다.

1.3.0 이하를 사용 중이면 이 APK를 한 번 직접 설치하세요. 앱을 삭제할 필요는 없습니다. 이후에는 앱 설정에서 업데이트할 수 있습니다.
