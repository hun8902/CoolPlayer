Cool Player for Android 1.4.5 (versionCode 30)

- 플레이어의 … 메뉴에 ‘전체 화면 가사’를 추가했습니다.
- 전체 화면에서 앨범아트 배경에 어두운 레이어와 그라데이션을 적용하고 큰 가사를 표시합니다.
- 전체 화면 하단에 재생 위치 조절, 이전 곡, 재생·일시정지, 다음 곡 버튼을 제공합니다.
- 전체 화면에서 뒤로가기 또는 상단 화살표를 누르면 기존 플레이어로 돌아갑니다.
- 곡 전환 시 전체 화면의 가사와 배경을 갱신하도록 처리했습니다.
- 전체 화면 진입 시 발생하던 레이아웃 삭제 충돌을 수정했습니다.
- 새 메뉴의 지원 언어 번역을 추가했습니다.

- 최근 앱에서 밀어서 닫을 때 재생을 중지하는 수정이 포함되어 있습니다.
