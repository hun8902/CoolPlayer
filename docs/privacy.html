COOL PLAYER · PRIVACY POLICY

개인정보처리방침

CoolPlayer는 사용자의 기기에 저장된 음악을 재생하고, 필요한 경우 가사를 검색·표시하는 음악 플레이어입니다. 서비스의 정보 처리 방식과 이용자의 권리를 다음과 같이 안내합니다.

시행일: 2026년 10월 22일 · 적용 서비스: CoolPlayer Android / Mac

운영자 및 적용 범위 처리 목적과 항목 온라인 기능 보유기간 및 파기 제3자 제공·위탁 정보주체의 권리 접근 권한 안전성 확보 자동 수집 장치 보호책임 및 문의 권익침해 구제 시행 및 변경

핵심 안내 — CoolPlayer는 별도의 회원가입 없이 사용할 수 있는 로컬 음악 플레이어입니다. 음악 파일, 재생목록, 가사 편집 내용과 설정은 주로 사용자의 기기에서 처리됩니다. 가사 검색, 온라인 이미지 불러오기, 앱 업데이트 기능은 해당 기능의 제공을 위해 인터넷 연결을 사용합니다.

제1조. 개인정보처리자 및 적용 범위

본 방침은 CoolPlayer(Cool Player)의 Android 및 Mac 앱에 적용됩니다. 서비스 개발·운영 관련 문의는 아래 개인정보 문의 창구를 이용할 수 있습니다.

CoolPlayer는 회원가입 및 로그인 기능을 제공하지 않으며, 음악 파일을 재생하기 위한 별도의 개발자 운영 계정 서버를 두고 있지 않습니다.

제2조. 정보의 처리 목적 및 항목

CoolPlayer는 아래 기능을 제공하기 위해 사용자가 선택한 음악 정보와 앱 설정을 처리합니다. 기기 내 데이터 처리와 온라인 서비스 요청을 구분해 안내합니다.

구분처리 정보와 목적처리 위치
음악 재생·보관함사용자가 선택한 음원 파일, 곡명·가수명·앨범 정보, 앨범 이미지 등을 이용하여 재생·분류 및 표시사용자 기기
가사·즐겨찾기가사 파일(LRC/TXT), 가사 편집 내용, 재생목록·즐겨찾기 등 편의 기능 제공사용자 기기
앱 환경설정언어, 테마, 가사 크기·타이밍, 재생 및 업데이트 확인 설정 등의 유지사용자 기기
온라인 요청사용자가 입력하거나 음악 메타데이터에서 얻은 검색어를 이용한 가사 검색, 앨범 이미지 주소 불러오기, 업데이트 버전 확인해당 기능 이용 시 외부 서비스에 요청

Mac 앱의 음원 정보 편집과 파일 형식 변환 역시 사용자의 로컬 파일을 대상으로 실행됩니다.

제3조. 온라인 기능을 통한 정보 처리

CoolPlayer는 사용자가 선택한 온라인 기능 또는 사용자가 활성화한 업데이트 확인 설정에 따라 다음 서비스와 통신합니다.

서비스이용 목적 및 요청 내용
가사 검색 서비스가사 검색·가져오기: 검색어 또는 곡명·가수명으로 검색 결과와 가사 조회 (Bugs, LRCLIB 등)
음악·이미지 검색 서비스앨범 이미지 및 음악 정보 검색: 검색어 또는 사용자가 지정한 HTTPS 이미지 주소로 결과 조회 (iTunes 등)
GitHub Releases업데이트 확인: 공개된 버전 정보 조회, 사용자가 선택한 업데이트 파일 다운로드. 자동 확인을 활성화했다면 앱 사용 중 설정에 따라 정기적으로 조회

이러한 온라인 요청은 사용자가 보유한 음원 파일 자체를 업로드하는 기능과 다릅니다. 인터넷 서비스 접속 시 필요한 통신 정보나 요청 기록은 각 서비스 운영 정책에 따라 처리될 수 있습니다.

제4조. 보유기간 및 파기절차·방법

기기 내 자료: 앱 환경설정, 재생목록, 즐겨찾기와 가사 편집 내용 등은 사용자가 관리하는 기기에 저장되며, 앱 내 삭제 기능이나 운영체제의 앱 데이터 삭제 기능으로 제거할 수 있습니다. 앱 전용 데이터는 앱 삭제 및 운영체제의 데이터 처리 정책에 따릅니다.

사용자 소유 파일: 사용자가 원래 보유한 음원과 앱 외부에 따로 저장·내보낸 가사 등은 앱의 삭제와 별개로 보관됩니다. CoolPlayer가 사용자 보관 파일의 삭제를 대신 수행하지 않습니다.

외부 서비스: 외부 서비스에서 생성한 요청·접속 기록의 보유기간과 삭제 기준은 각 외부 서비스의 방침에 따릅니다. CoolPlayer는 이를 자체 사용자 계정 기록으로 관리하지 않습니다.

제5조. 제3자 제공 및 처리업무 위탁

현재 확인된 앱 기능상, 개발자가 운영하는 서버에 사용자의 음악 파일이나 회원정보를 수집·보관한 뒤 광고 목적 등으로 제3자에 제공하는 구조는 없습니다.

다만 제3조의 검색 및 업데이트 기능을 이용하는 경우, 필요한 검색어·요청 정보가 해당 외부 서비스에 전달됩니다. 이는 해당 기능의 동작에 필요한 서비스 연결이며, 각 제공업체의 개인정보 처리 기준이 별도로 적용됩니다.

현재 확인된 앱 코드에는 이용자 개인정보를 보관·처리하도록 별도 수탁업체에 위탁하는 기능이 확인되지 않았습니다. 처리 방식이 변경되면 이 방침을 갱신하겠습니다.

제6조. 정보주체와 법정대리인의 권리 및 행사방법

이용자는 언제든지 기기에 보관된 CoolPlayer 설정, 재생목록 및 가사 정보 등을 확인하거나, 앱에서 제공하는 방법 또는 운영체제의 앱 데이터 관리 기능으로 정정·삭제할 수 있습니다.

개인정보 열람, 정정·삭제, 처리정지 등에 대한 요청이나 문의는 아래 제10조의 문의 창구를 통해 접수할 수 있습니다. 법정대리인도 관련 법령에 따라 권리를 행사할 수 있습니다. 개발자가 보유하지 않는 이용자 기기 내 파일은 개발자가 직접 열람·삭제하지 않습니다.

제7조. 앱 접근 권한의 이용

Android 앱의 코드에 정의된 기능별 권한은 다음과 같습니다. 실제 접근은 Android 버전 및 이용자의 권한 허용 설정에 따라 달라집니다.

기능사용 목적
파일·폴더 선택사용자가 선택한 음악, 가사 및 관련 파일을 재생하거나 불러오기
알림음악 재생 상태 및 미디어 컨트롤 표시
백그라운드 재생화면이 꺼지거나 다른 앱을 사용하는 동안 음악 재생 유지
인터넷 연결가사 검색, 이미지 요청, 업데이트 확인·다운로드
업데이트 설치사용자가 앱 외부 배포판 업데이트 설치를 선택했을 때 Android의 설치 절차 이용

제8조. 개인정보의 안전성 확보조치

음악 재생과 설정 관리에 사용되는 정보는 기본적으로 이용자의 기기에서 처리되도록 구성되어 있습니다. 현재 확인된 앱 구현에서는 외부 연결에 HTTPS를 사용하도록 설정되어 있습니다.

기기의 파일 접근과 앱 권한은 운영체제의 보안 정책 및 사용자가 지정한 권한 범위에 따릅니다. 외부 서비스의 정보 처리 및 통신 보안은 해당 서비스의 정책을 적용받습니다.

제9조. 자동 수집 장치의 설치·운영 및 거부

확인된 Android 앱 코드에는 사용자 행동을 추적하기 위한 별도 광고 식별자나 웹 쿠키 설정 기능이 확인되지 않았습니다. 업데이트 자동 확인 기능을 사용하는 경우 해당 기능의 설정에서 동작 여부를 관리할 수 있습니다.
