필요한 작업만 처리합니다.

파일 목록을 기준으로 변환, 정보 수정, 가사 저장, 재생 확인까지 이어집니다.

01

원본 음원 분석

파일 형식, 비트 깊이, 샘플레이트를 읽어 목록에서 바로 볼 수 있게 표시합니다.

02

ALAC 변환

FLAC 파일을 iPhone에서 다루기 쉬운 ALAC `.m4a` 형식으로 변환합니다.

03

곡 정보 수정

제목, 아티스트, 앨범명, 커버 이미지를 확인하고 필요한 정보를 보완합니다.

04

LRC 가사 저장

실시간 가사를 불러오거나 편집한 뒤 원본 파일명에 맞춰 저장합니다.

사용법

처음 써도 흐름이 보이게.

FLAC을 넣고, 체크한 파일만 변환하고, 결과를 바로 재생해 확인하는 흐름입니다.

1
파일 또는 폴더 추가FLAC 파일을 드래그하거나 선택해서 목록에 추가합니다.
2
원본 정보 확인앨범아트와 음원 정보를 보고, 필요한 메타데이터를 수정합니다.
3
ALAC 변환선택한 파일만 변환하고 지정한 위치에 저장합니다.
4
결과 재생변환된 파일이 정상적으로 재생되는지 바로 확인합니다.
앱 화면 기준 왼쪽 파일 리스트에서 체크한 항목만 오른쪽 변환 화면에 표시됩니다. 출력 품질과 저장 위치를 고른 뒤 변환을 시작합니다. 완료된 파일은 하단 플레이어 바에서 바로 재생 확인합니다.
화면

앱 안의 화면 흐름 그대로.

실제 앱의 오른쪽 메뉴 구성을 기준으로 각 화면에서 하는 일을 설명합니다.

01 변환 화면

체크한 FLAC만 ALAC로 변환

왼쪽 파일 리스트에서 체크한 파일만 오른쪽 변환 화면에 표시됩니다. 출력 품질, 저장 위치, 진행 상태를 확인하고 변환을 시작합니다.

출력 품질저장 위치진행 상태
02 정보 화면

앨범아트와 메타데이터 확인

선택한 음원의 앨범 커버와 메타데이터를 확인합니다. 곡명, 아티스트, 앨범 정보를 수정하고 파일에 저장할 수 있습니다.

앨범 커버곡명아티스트앨범
03 가사 화면

LRC 가사를 불러오고 저장

선택한 곡 정보를 기준으로 실시간 가사를 불러오거나 직접 편집합니다. 저장할 때는 원본 파일명과 같은 이름의 `.lrc` 파일을 기본값으로 사용합니다.

자동 검색직접 편집LRC 저장
04 기록 화면

작업 결과를 시간순으로 확인

분석, 변환, 메타데이터 저장, 가사 저장 같은 작업 결과가 쌓이는 화면입니다. 여러 파일을 처리한 뒤 어떤 작업이 끝났는지 다시 확인할 수 있습니다.

분석 기록변환 기록저장 기록
음질

ALAC 24-bit / 192kHz 기준으로 정리합니다.

고해상도 FLAC 파일을 Apple 기기에서 다루기 쉬운 ALAC 형식으로 변환하고, 변환 결과를 앱 안에서 바로 확인하는 흐름을 목표로 합니다.

FORMATALAC `.m4a`iPhone과 Apple 생태계에서 다루기 쉬운 무손실 오디오 형식입니다.
QUALITY24-bit / 192kHz고해상도 음원을 기준 출력으로 맞춰 라이브러리를 정리합니다.
LYRICSLRC 실시간 가사곡과 같은 이름의 `.lrc` 파일을 만들어 플레이어 연동을 준비합니다.
